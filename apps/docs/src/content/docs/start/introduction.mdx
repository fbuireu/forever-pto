Forever PTO turns a fixed budget of PTO Days into the longest possible stretches off. You give it a Country, the number of PTO Days you have and a Strategy, and it suggests which days to spend so that weekends and Holidays join into long stretches off. The core idea is the **Bridge**: a short run of PTO Days that joins a weekend to a Holiday (or two Holidays to each other), so that one or two PTO Days yield four or more consecutive Effective Days. The [glossary](/reference/glossary/) defines every capitalised term in this wiki.

The app runs at [forever-pto.com](https://forever-pto.com) as a Cloudflare Worker.

## How this site is built

This wiki is an Astro Starlight site in the `apps/docs/` workspace package. Its design-system pages render the **actual app components** as React islands, imported through the `@ui` alias, and type their demos against the app's own variant definitions, so a variant renamed in the app fails `astro check` here. Prose follows the same rule: where the app exports a constant, the page imports it instead of copying the value. The [Button page](/design-system/components/button/) is the reference example, and [how this wiki is built](/contributing/docs-site/) covers the mechanics.
