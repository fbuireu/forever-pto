Both components are client-only Motion consumers and require a `LazyMotionProvider` ancestor. `SlidingNumber` additionally reads the active locale through `next-intl` to pick its decimal separator, so `Demo.tsx` supplies a `DemoIntlProvider` beside the Motion provider, an app context the component needs to run at all.

## SlidingNumber

`SlidingNumber` (`apps/web/src/ui/modules/core/animate/text/SlidingNumber.tsx`) renders a number as a stack of odometer rollers: each digit is a `1ch`-wide window over a column of 0–9 `m.span`s, and a per-digit spring (`stiffness: 200, damping: 20, mass: 0.4`) rolls the column the shortest way to the target digit. Digits are measured with `react-use-measure`, so the roller adapts to the surrounding font.

<SlidingNumberDemo client:visible />

Props beyond `number`: `className`, `padStart`, which zero-pads single-digit integers, and `decimalPlaces`, which sets the fraction digits; the separator is the active locale's. Negative numbers render a leading minus sign.

This is the number display inside [Counter](/design-system/animation/components/), which the sidebar uses for the PTO-days stepper (`apps/web/src/ui/modules/sidebar/components/PtoDays.tsx`).

## RotatingText

`RotatingText` (`apps/web/src/ui/modules/core/animate/text/Rotating.tsx`) animates a string in and out through `AnimatePresence` in `wait` mode whenever the `text` it receives changes: the old text slides up and fades out, the new one slides in from below. The caller owns the changing, as the dev footer's emoji and the Summary's first and last rest blocks do; an optional `transition` overrides the default 0.3 s ease-out.

## Usage

```tsx
import { SlidingNumber } from '@ui/modules/core/animate/text/SlidingNumber';
import { RotatingText } from '@ui/modules/core/animate/text/Rotating';

<SlidingNumber number={efficiency} decimalPlaces={1} />

<RotatingText text={currentWord} />
```

## Conventions

- `SlidingNumber` renders `tabular-nums` rollers, so keep the surrounding type style on the component itself
 (`className`) so the measurement matches the render.
- `RotatingText` renders a `div`, so it goes in a `div` or another flow container, never in a `<p>` or a heading:
 the HTML parser closes the paragraph before the `div`, and React fails the hydration (error #418).
- Both components expose `data-slot` attributes (`sliding-number`, `sliding-number-roller`, `sliding-number-display`) for CSS containment hooks.
