Source: `apps/web/src/ui/modules/core/animate/components/`. Composite motion components (`Tabs.tsx` in the same directory is documented with the other Base UI wrappers). `FeatureList` and `RadialNav` are framework-clean: Motion, `cn()`, `lucide-react` and the core `Badge` are their only dependencies. `Counter` wraps [SlidingNumber](/design-system/animation/text/), which reads the locale through `next-intl`, and `Demo.tsx` supplies the `DemoIntlProvider` it needs. All three render the real components; as always with `m.*` consumers, they need a `LazyMotionProvider` ancestor.

## Counter

`Counter` (`Counter.tsx`) is a stepper: minus and plus `m.button`s flanking a [SlidingNumber](/design-system/animation/text/) inside a brutal-framed pill, with `layout` animation so the pill resizes smoothly as digit count changes. The layout is keyed on the number with `layoutDependency`, so Motion measures the pill only when the value moves rather than on every render of whatever hosts it. It is controlled: pass `number` and `setNumber`. **`decrementLabel` and `incrementLabel` are required**: the two buttons render a glyph and nothing else, so without them a screen reader announces "button, button". Also required: `label` (the small caption under the number) and `decrementButtonProps` / `incrementButtonProps`, each carrying the `disabled` flag that stops the number at a bound.

## FeatureList

`FeatureList` (`FeatureList.tsx`) is the roadmap card deck: features render as stacked cards, collapsed into a fanned pile (`marginTop: -44`, progressively narrower `scaleX`) that expands to a full list on hover or tap, while the footer cross-fades between `categoryLabel` and `detailedViewLabel`. Props: `features: { id, title, description, quarter? }[]` (the optional `quarter` renders a secondary `Badge`), `categoryLabel`, `detailedViewLabel`.

## RadialNav

`RadialNav` (`RadialNav.tsx`) is a circular menu: items are placed by polar coordinates on a ring of 180 px diameter, and a central `MousePointer2` cursor rotates to the active item along the shortest arc (spring `stiffness: 220, damping: 26`). The active button expands from a 40 px circle to reveal its uppercase label.

<RadialNavDemo client:visible />

Props: `items: { id, icon, label, angle, animateOnHover?, badgeClass?, className? }[]`, where `icon` is any component that takes the `className` and `style` the button gives it: a Lucide icon or one of the [animated icons](/design-system/animation/icons/). `animateOnHover` asks an animated icon to play when the pointer is over it; set it on an animated icon only, since a Lucide icon would hand it to its `<svg>` as an unknown attribute. An item that leaves it out passes its icon no `animateOnHover` at all, not an undefined one, so a Lucide icon there renders without that warning. `badgeClass` recolors the active state (default `bg-accent`). Plus `defaultActiveId`, `onActiveChange` and `aria-label`, all required: the nav is a `fieldset` named by the caller, since the component cannot translate. The active item is found by its `id`, so ids need only be unique.

## Usage

```tsx
import { Counter } from '@ui/modules/core/animate/components/Counter';
import { FeatureList } from '@ui/modules/core/animate/components/FeatureList';
import { RadialNav } from '@ui/modules/core/animate/components/RadialNav';

<Counter
  number={days}
  setNumber={setDays}
  label='days'
  decrementLabel='Decrease PTO days'
  incrementLabel='Increase PTO days'
  decrementButtonProps={{ disabled: days <= MIN_DAYS }}
  incrementButtonProps={{ disabled: days >= MAX_DAYS }}
/>

<FeatureList features={features} categoryLabel='Completed' detailedViewLabel='Detailed view' />

<RadialNav
  items={[{ id: 1, icon: CircleCheckBig, animateOnHover: true, label: 'Completed', angle: 0 }]}
  defaultActiveId={1}
  onActiveChange={setCategory}
  aria-label='Feature navigation'
/>
```

## Conventions

- These components stay presentation-only: labels arrive as props, never from `useTranslations`, and the contract suite fails a translation inside `core/`.
- `RadialNav` takes no `className` (its props type has none), so wrap it in a positioned container and leave room around the ring for the expanding buttons.
- Related: [effects](/design-system/animation/effects/), [text animations](/design-system/animation/text/), [animated icons](/design-system/animation/icons/).

## In the app

`Counter` is the PTO-days stepper of the sidebar (`PtoDays.tsx`) and of the quick start (`QuickStartPtoDaysStep.tsx`). `FeatureList` and `RadialNav` make up the planner's roadmap (`Roadmap.tsx`): the ring picks a status, the deck lists that status's features.
