## How it works

- The root is a Base UI switch rendered through an `m.button`: a 60px-wide pill with 3px frame border and hard shadow. Controlled and uncontrolled modes go through `useControlledState` (`apps/web/src/ui/hooks/useControlledState.tsx`), so `checked`, `defaultChecked` and `onCheckedChange` behave like the rest of the system.
- The thumb is an `m.div` that translates 28px to the right when checked (via Base UI's `data-checked` attribute) and flips from frame-on-frame to accent-on-frame coloring. The travel uses a linear 0.15s tween.
- Press feedback is context-driven: the root tracks tap state (`onTapStart`/`onTapCancel`/`onTap`) and shares it with the thumb, which can react through its `pressedAnimation` prop. Pass custom `children` to `Switch` if you want a thumb with icons or a squish animation. Press state is the *only* thing on that context; it used to also carry the checked value and its setter, which nothing read.
- Disabled state washes out border, background and shadow with `color-mix` so the hard shadow fades consistently in both themes.

## Usage

```tsx
import { Switch } from '@ui/modules/core/animate/base/Switch';

<Switch id='carryover' checked={enabled} onCheckedChange={(next) => setEnabled(next)} />
<Label htmlFor='carryover'>Enable carryover</Label>
```

Use Switch for immediate on/off settings; use [Checkbox](/design-system/components/checkbox/) for form selections that are submitted later.

## Conventions

- **An accessible name is required, and the type says so.** The props are intersected with
  `{ id: string } | { "aria-label": string } | { "aria-labelledby": string }`, so a `Switch` with none of
  them does not compile. It renders a `button` with no text inside it, so without one it reaches a screen
  reader as "switch, not pressed" and nothing else. Pass `id` when a visible `Label` names it (the `Label`
  needs the matching `htmlFor`, which is also required), and `aria-label` when there is no visible label.
- `data-slot` hooks: `switch`, `switch-thumb`.
- Form integration comes from Base UI: `name`, `required`, `readOnly` and `inputRef` forward to a hidden input.

## Accessibility

- Base UI renders `role='switch'` with `aria-checked`; Space toggles, and the root is a real button, so Enter works too.
- The accessible name is enforced by the type, exactly as on Checkbox: `id` with a Label, or `aria-label` / `aria-labelledby`.
- The 60×32 pill clears the touch-target minimum on its own, and the thumb squash while pressed is purely visual.
