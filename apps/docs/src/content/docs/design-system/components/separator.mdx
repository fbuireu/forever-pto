Source: `apps/web/src/ui/modules/core/primitives/Separator.tsx`. A `bg-border` hairline div. The only primitive in the system deliberately without the brutal border treatment: it separates, it does not frame.

## Props

| Prop | Values | Behavior |
| --- | --- | --- |
| `orientation` | `horizontal` (default), `vertical` | `h-px w-full` vs `h-full w-px`. A vertical separator needs a parent with an explicit height. |
| `decorative` | `true` (default), `false` | Decorative renders `role='none'` (invisible to assistive tech). Non-decorative renders `role='separator'` with `aria-orientation`. |

## Usage

```tsx
import { Separator } from '@ui/modules/core/primitives/Separator';

<Separator />

<div className='flex h-6 items-center gap-4'>
  <span>Grouped</span>
  <Separator orientation='vertical' />
  <span>Optimized</span>
</div>
```

## Conventions

- Keep `decorative` (the default) for purely visual dividers; set `decorative={false}` only when the separation is semantically meaningful (e.g. between toolbar groups).
- It is a plain div, so all `ComponentProps<'div'>` pass through, and `className` merges via `cn()`.

## Accessibility

- Decorative by default: `role='none'`, invisible to assistive technology, which is right for a hairline between two blocks of related content.
- Set `decorative={false}` when the line marks a boundary a screen reader should announce; it then carries `role='separator'` and `aria-orientation`.

## In the app

No feature module renders `Separator` today; the hairlines in the app are drawn with border utilities on the components themselves. It exists for composition and for the docs.
