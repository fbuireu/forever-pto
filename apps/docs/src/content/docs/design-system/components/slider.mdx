## How it works

- **Value normalization is the whole point of the wrapper.** Base UI emits `number` for single-thumb sliders and `readonly number[]` for ranges; consumers always want a mutable `number[]`. The component wraps `onValueChange` so it always receives `number[]`, and `value` is an array too.
- `onValueChange` fires continuously while dragging.
- Anatomy: `Root > Control > Track (surface-panel-alt, 3px frame border) > Indicator (frame-colored fill)` plus a `size-7` accent thumb with `hit-area-stable` and the standard hover lift (translate -0.5, shadow grows), same mechanics as [Button](/design-system/components/button/).

## Usage

```tsx
import { Slider } from '@ui/modules/core/primitives/Slider';

<Slider
  label='Carry-over months'
  value={[months]}
  min={1}
  max={12}
  step={1}
  onValueChange={([next]) => setMonths(next)}
/>
```

## Conventions

- **`label` is required.** It becomes the thumb's `aria-label`: a slider with no visible text label is unusable with a screen reader, so the type refuses to let one ship rather than leaving it to a review.
- The rest of the prop surface is a deliberate subset (`value`, `min`, `max`, `step` and `onValueChange`, all required, since every caller sets them); extend the interface in the source if you need more of Base UI's API rather than reaching for the primitive directly. There is no `id`: it would land on the wrapper `div` Base UI renders, so a `<label for>` pointing at it would name nothing, which is why `label` is required instead.

## Accessibility

- Base UI renders each thumb as `role='slider'` with `aria-valuenow`, `aria-valuemin` and `aria-valuemax`; the required `label` prop becomes the thumb's `aria-label`, which is why it is not optional.
- Keyboard: arrow keys move by `step`, Page Up and Page Down by a larger step, Home and End to the bounds. The thumb is `size-7`, above the 24px minimum target, and `touch-none` stops the page from scrolling while dragging on touch screens.
- `onValueChange` fires on every pixel of a drag, so debounce anything expensive in the callback.
