Source: `apps/web/src/ui/modules/core/animate/base/Checkbox.tsx`. A Base UI checkbox whose root is rendered as `m.button` (`whileTap` scale 0.95, `whileHover` scale 1.05), so it needs a `LazyMotionProvider` ancestor.

Exports: `Checkbox`.

<CheckboxDemo client:visible />

## How it works

- The check mark is an `m.svg` path animated via `pathLength`: checking draws the stroke in (0.2s, after a 0.2s delay so the background color lands first); unchecking retracts it. The indicator is `keepMounted` so the retract animation can play.
- The component mirrors `checked` into local state to drive the SVG variants, and forwards `onCheckedChange` untouched (Base UI signature: `(checked, eventDetails)`).
- Visuals: `size-5`, 3px frame border, `shadow-brutal-xs`; checked state flips to `bg-accent` with ink-colored stroke.

## Usage

```tsx
import { Checkbox } from '@ui/modules/core/animate/base/Checkbox';

<Checkbox
  checked={checked}
  onCheckedChange={(next) => setChecked(next)}
  aria-label='Select Christmas Day'
/>
```

For an on/off setting rendered as a toggle, use [Switch](/design-system/components/switch/) instead.

## Conventions

- `data-slot='checkbox'` and `data-slot='checkbox-indicator'` for CSS containment hooks; checked styling keys off Base UI's `data-checked` attribute.
- The `render` and `nativeButton` props are reserved by the component (it injects the `m.button` and tells Base UI it is a native button), so both are omitted from the public prop type.

## Accessibility

- Base UI renders `role='checkbox'` with `aria-checked`, and Space toggles it. The root is a button, so it is in the tab order and gets the focus ring.
- The accessible name is required by the type: `aria-label` names the box, since it renders a button with no text of its own. Nothing else compiles.
- The drawn check is an SVG path animation; `keepMounted` keeps the indicator in the DOM so the retract can play, and the state a screen reader hears comes from `aria-checked`, not from the drawing.
