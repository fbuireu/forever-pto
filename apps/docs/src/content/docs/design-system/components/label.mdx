Source: `apps/web/src/ui/modules/core/primitives/Label.tsx`. A styled native `<label>` (small, medium weight, tight leading). It carries no logic: association happens through the standard `htmlFor` attribute passed via props.

## Usage

```tsx
import { Input } from '@ui/modules/core/primitives/Input';
import { Label } from '@ui/modules/core/primitives/Label';

<Label htmlFor='pto-days'>PTO days per year</Label>
<Input id='pto-days' inputMode='numeric' />
```

## Conventions

- The app's form layer (`apps/web/src/ui/modules/core/primitives/Form.tsx`, reference-only here) wraps this same component as `FormLabel` and adds error coloring plus automatic `htmlFor` wiring.
- Pair with [Input](/design-system/components/input/) and [Textarea](/design-system/components/textarea/).

## Accessibility

- The association is the native one: `htmlFor` pointing at the control's `id`, which the type makes mandatory. Clicking the label focuses the control, and a screen reader announces the label when the control is focused.

## In the app

The consent toggles in `CookieConsentDialog.tsx` and the country and region captions of the quick start (`InlineQuickStartForm.tsx`, `QuickStartLocationStep.tsx`). The sidebar's fields do not use it: `SidebarFieldLabel.tsx` draws a native `<label>` with a tooltip trigger inside.
