Source: `apps/web/src/ui/modules/core/primitives/Banner.tsx`. A bordered, shadowed callout box (`role='note'`, labelled by its `title`) with an icon row on top and the message below. Framework-clean, so this page renders the real component.

## Color schemes

`colorScheme` is not a CVA axis: it indexes a `COLOR_SCHEMES` lookup object in the source file that maps each scheme to four `wash-*` utilities (background, icon, title, message). The tokens behind them are in `apps/web/src/ui/styles/global/index.css`: a `color-mix()` of the brand colour, with separate light and dark values. The app uses `orange` for an improvement it found, `indigo` for the Premium notice and the user's manual edits, and `blue` for hints about the user's region and custom holidays.

## Icon and action

`icon` accepts either a Lucide icon or one of the animated icon components from `apps/web/src/ui/modules/core/animate/icons/` (they share the same call signature). The optional `action` slot renders any node below the message with top margin. The Summary's *You can improve* banner passes a link or button drawn like a small [Button](/design-system/components/button/) in the banner's own colour.

## Usage

```tsx
import { Banner } from '@ui/modules/core/primitives/Banner';
import { MapPin } from 'lucide-react';

<Banner colorScheme='blue' icon={MapPin} title='Add your region'>
  Select your region in the sidebar to include regional holidays.
</Banner>
```

## Conventions

- `title` is rendered uppercase by CSS, so pass a normal-case string.
- The icon is `aria-hidden`; the accessible name comes from `aria-label={title}` on the container.
- `children` renders in a `flex flex-wrap items-baseline` row, so inline fragments (values, links) line up on the baseline.

## Accessibility

- `role='note'` with `aria-label` set to the `title`, so the box announces as a note named by its heading and its body is read as content.
- The icon is `aria-hidden`; the colour scheme carries no meaning on its own, which is why `title` is required.
- The optional `action` is a real control inside the note; make it a link or a `<button>` so it is reachable by keyboard.
