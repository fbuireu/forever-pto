## How it works

- `DropdownMenuContent` gates the portal behind `AnimatePresence` and renders the popup as an `m.div` scaling `0.95 → 1` with a fade (a 0.2s transition). The panel is the standard brutal popover surface: 3px frame border, `rounded-xl`, `shadow-brutal-md`, positioned at `z-210`, above a dialog's `z-200`, 4px from the trigger and aligned to its end.
- Hover highlighting is not per-item CSS: the content wraps children in `MotionHighlight` (`apps/web/src/ui/modules/core/animate/effects/MotionHighlight.tsx`), a single accent pill that glides between items. The pill is a spring (`stiffness: 350, damping: 35`). The same effect powers [Tabs](/design-system/components/tabs/) and the sidebar.
- `DropdownMenuItem` renders as an `m.div` with `whileTap` scale 0.97.
- `DropdownMenuTrigger` takes the single element it wraps, such as a [Button](/design-system/components/button/), and renders it in place through Base UI's `render`.

## Props

`DropdownMenu` forwards Base UI's menu root props, `DropdownMenuTrigger` and `DropdownMenuItem` forward the trigger's and the item's, and `DropdownMenuContent` forwards the Motion props of a `div`. None adds a prop of its own: placement and the hover pill are fixed.

## Usage

```tsx
import { DropdownMenu, DropdownMenuContent, DropdownMenuItem, DropdownMenuTrigger } from '@ui/modules/core/animate/base/DropdownMenu';

<DropdownMenu>
  <DropdownMenuTrigger>
    <Button variant='outline' size='icon'>
      <Sun />
      <span className='sr-only'>Toggle theme</span>
    </Button>
  </DropdownMenuTrigger>
  <DropdownMenuContent>
    <DropdownMenuItem onClick={() => setTheme('light')}>Light</DropdownMenuItem>
    <DropdownMenuItem onClick={() => setTheme('dark')}>Dark</DropdownMenuItem>
    <DropdownMenuItem onClick={() => setTheme('system')}>System</DropdownMenuItem>
  </DropdownMenuContent>
</DropdownMenu>
```

For free-form anchored content (forms, explanations) use [Popover](/design-system/components/popover/); DropdownMenu is for lists of actions with menu semantics and keyboard navigation.

## Conventions

- `data-slot` hooks: `dropdown-menu`, `dropdown-menu-trigger`, `dropdown-menu-content`, `dropdown-menu-item`.
- Content height is capped to Base UI's `--available-height` so long menus scroll instead of overflowing the viewport.

## Accessibility

- Base UI renders `role='menu'` and `role='menuitem'`, moves focus into the menu on open, supports arrow keys, Home and End, typeahead by first letter, and closes on Escape or on selecting an item, returning focus to the trigger.
- The hover pill follows the focused item as well as the hovered one, so keyboard users see the same highlight.
- The element the trigger wraps must be a button, or carry `role='button'` and `aria-haspopup='menu'`, which Base UI adds when it renders the button itself.

## In the app

The language switchers (`LanguageSelector.tsx` in the sidebar, `HomepageLanguageSwitcher.tsx` on the homepage) and the theme picker (`ThemeSelector.tsx`), each opened from a `Button` that the trigger wraps.
