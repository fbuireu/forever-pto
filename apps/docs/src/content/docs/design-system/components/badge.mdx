## Interactive only as a link

The hover lift (translate `-0.5, -0.5` plus a bigger shadow) is gated behind the `[a&]:` Tailwind selector, so it fires only when the badge renders as an `<a>` element, typically through `asChild`. A plain `<span>` badge stays inert.

## Usage

```tsx
import { Badge } from '@ui/modules/core/primitives/Badge';

<Badge variant='destructive'>3 conflicts</Badge>

// Render as a link, which unlocks the hover lift
<Badge asChild>
  <a href='/planner'>Open planner</a>
</Badge>
```

## Conventions

- The CVA object is exported alongside the component (`badgeVariants`), per the core conventions in `apps/web/src/ui/modules/core/CLAUDE.md`.
- `asChild` composes through the local `Slot` (`apps/web/src/ui/modules/core/animate/base/Slot.tsx`), same as [Button](/design-system/components/button/).
- `data-slot='badge'` is set for CSS containment hooks.
- `hit-area-stable` keeps the pointer hit-area steady during the link hover lift; see [Hit-area stability](/design-system/foundations/hit-area-stable/).
- SVG children are auto-sized to `size-3` and get `pointer-events: none`.

## Accessibility

- A plain `<span>` with no role: a Badge is decoration around text, and the text is what a screen reader announces. Write it in normal case; the uppercase is CSS, so the announcement is not spelled out letter by letter.
- As a link (`asChild` around an `<a>`) it gains the focus ring and the hover lift; as a span it is not focusable and should not carry a click handler.
