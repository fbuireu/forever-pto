## Conventions

- The CVA object stays inside the file; `apps/web/src/ui/modules/core/AGENTS.md` lists the components that use CVA.
- `data-slot='badge'` is set for CSS containment hooks.
- SVG children are auto-sized to `size-3` and get `pointer-events: none`.

## Accessibility

- A plain `<span>` with no role: a Badge is decoration around text, and the text is what a screen reader announces. Write it in normal case; the uppercase is CSS, so the announcement is not spelled out letter by letter. It is not focusable and should not carry a click handler.
