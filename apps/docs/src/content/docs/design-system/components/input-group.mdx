Source: `apps/web/src/ui/modules/core/primitives/InputGroup.tsx`. The group owns the frame: one `role='group'` container carries the border, background and shadow states, while `InputGroupInput` renders a borderless, transparent [Input](/design-system/components/input/) inside it. Focus and `aria-invalid` styling bubble from the control to the container through `has-[…]` selectors, so the whole group highlights as a unit.

## Composition

`InputGroupAddon` always sits before the control, at the inline start: the container reads its `data-align` attribute to trim the control's left padding. `InputGroupText` styles an inline text or icon fragment inside an addon, such as a currency sign. Clicking an addon focuses the inner input.

## Props

`InputGroup`, `InputGroupAddon` and `InputGroupText` take a `div`'s, a `div`'s and a `span`'s props respectively and add none; `InputGroupInput` takes the native input's.

## Usage

```tsx
import { InputGroup, InputGroupAddon, InputGroupInput, InputGroupText } from '@ui/modules/core/primitives/InputGroup';

<InputGroup>
  <InputGroupAddon>
    <InputGroupText>€</InputGroupText>
  </InputGroupAddon>
  <InputGroupInput placeholder='50,000' />
</InputGroup>
```

## Conventions

- Exported parts: `InputGroup`, `InputGroupAddon`, `InputGroupInput`, `InputGroupText`.
- `InputGroupInput` sets `data-slot='input-group-control'`, which the container's focus and error selectors target.
- Set `aria-invalid` on the inner control; the container mirrors it (destructive border, destructive focus shadow).

## Accessibility

- The container is `role='group'`, so the input and its addons announce as one field. Give the group an `aria-label` or point `aria-labelledby` at a caption when the addons carry meaning (a currency, a unit).
- Clicking an addon focuses the input, a pointer convenience only: keyboard and screen-reader users reach the input directly, which is why the addon is not itself focusable.
- The focus and invalid rings move from the control to the container through `has-[…]` selectors, so the whole group highlights while the accessible state stays on the input.

## In the app

The annual salary and unused-days fields of `PtoSalaryCalculator.tsx` and the amount field of the Donation form in `DonationForm.tsx`, each drawn through `NumberInput` with `InputGroupInput` as its field.
