## Unit tests (Vitest)

Configured in `apps/web/vitest.config.ts` with `resolve.tsconfigPaths: true`, so all the app's path aliases (`@ui`, `@domain`, …) work in tests without extra mapping.

- **Environment**: happy-dom.
- **Setup** (`vitest.setup.ts`): runs Testing Library's `cleanup` after each test.
- **Excluded from the runner**: `apps/web/e2e/**`, generated bones, icon directories and i18n message JSON.
- **Coverage**: v8 provider over `apps/web/src/**/*.{ts,tsx}` (tests, `*.d.ts`, `types.ts` files and generated code excluded), reported as text + lcov. `ci.yml` runs `pnpm test:ut:coverage` and uploads `apps/web/coverage/lcov.info` to Codecov on every push and PR.

Run locally with `pnpm test:ut` (or `pnpm test:ut:coverage`).

## End-to-end tests (Playwright)

There are **independent suites**:

### App suite, root `apps/web/e2e/`

Configured in `apps/web/playwright.config.ts`. Specs mirror the app's route structure (`apps/web/e2e/[locale]/(app)/planner/planner.spec.ts`, `apps/web/e2e/api/health.spec.ts`, …), which makes it obvious which route a failing spec covers.

- `baseURL` comes from the `BASE_URL` env var; without it the config starts `pnpm dev` and targets `http://localhost:3000`.
- In CI these tests run **against the live per-PR preview deployment**, authenticating through Cloudflare Access with a service token (`CF_ACCESS_CLIENT_ID`/`CF_ACCESS_CLIENT_SECRET` injected as headers by the config). See [environments](/infra/environments/).
- CI runs chromium only with retries; locally you get chromium, firefox and webkit.

### Docs suite, `apps/docs/e2e/`

Configured in `apps/docs/playwright.config.ts`: every spec in `apps/docs/e2e/` runs against the built site through `astro preview` (`webServer` block), chromium only, so the site has to be built first; the `@smoke` cases in `smoke.spec.ts` also run against the deployed site after a production deploy. It runs in `.github/workflows/docs.yml` after the build.

## File conventions

| Kind | Pattern | Location |
| --- | --- | --- |
| Unit test | `*.test.ts` / `*.test.tsx` | Colocated next to the source file it tests |
| E2E test | `*.spec.ts` | Only in `apps/web/e2e/` (or `apps/docs/e2e/`), mirroring routes |

Keep the split strict: the Vitest runner excludes `apps/web/e2e/**`, and `test:ut:changed`, which `pre-push` runs through `verify:changed`, relies on the colocation to find the tests a change affects (see [tooling](/contributing/tooling/)).
