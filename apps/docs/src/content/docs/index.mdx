## The whole product in one picture

Everything that matters happens in the browser: the edge only detects a Country and serves prerendered HTML, and the plan itself never leaves the device.

```mermaid
flowchart TB
  subgraph edge [Cloudflare Worker]
    PX[Proxy: locale + Country cookies]
    API["/api/*: Donation, session, contact"]
  end
  subgraph browser [Browser]
    ST[(Zustand stores<br/>encrypted localStorage)]
    HOL[date-holidays, bundled]
    UI[Planner screen]
    WK[Web Worker<br/>planning engine]
  end
  PX -->|HTML + cookies| UI
  UI <--> ST
  ST --> HOL --> ST
  ST -->|ISO strings| WK -->|Suggestion + Alternatives + Metrics| ST
  UI -->|Donation only| API
```
