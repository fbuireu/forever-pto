## Todo el producto en una imagen

Lo importante ocurre en el navegador: el edge solo detecta un Country y sirve HTML prerenderizado, y el plan nunca sale del dispositivo.

```mermaid
flowchart TB
  subgraph edge [Cloudflare Worker]
    PX[Proxy: cookies de locale y Country]
    API["/api/*: Donation, sesión, contacto"]
  end
  subgraph browser [Navegador]
    ST[(Stores de Zustand<br/>localStorage ofuscado)]
    HOL[date-holidays, en el bundle]
    UI[Pantalla del planificador]
    WK[Web Worker<br/>motor de planificación]
  end
  PX -->|HTML + cookies| UI
  UI <--> ST
  ST --> HOL --> ST
  ST -->|cadenas ISO| WK -->|Suggestion + Alternatives + Metrics| ST
  UI -->|solo la Donation| API
```
